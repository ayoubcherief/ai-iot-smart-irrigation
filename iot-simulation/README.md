# IoT Simulation — Smart Irrigation System

This folder contains the documentation for the ESP32-based smart irrigation system simulated using Wokwi.

## Components

- ESP32 microcontroller
- DHT22 temperature and humidity sensor
- LCD display
- Servo motor
- LEDs
- Potentiometer used to simulate soil moisture levels

## How It Works

The ESP32 reads simulated sensor inputs and applies rule-based logic to determine the irrigation response. The LCD displays system information, while the LEDs and servo motor represent the system's status and irrigation mechanism.

## Current Implementation

The IoT simulation operates independently of the machine learning notebook. The AI model has not yet been integrated into the ESP32 control logic.
