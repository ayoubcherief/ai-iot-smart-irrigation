# AI Model — Soil Moisture Classification

This folder contains the Google Colab notebook for the machine learning component of the Smart Irrigation project.

The notebook explores data preprocessing, model training, and evaluation to classify soil moisture conditions into four categories:

- Dry
- Very Dry
- Wet
- Very Wet

## Models Evaluated

- Logistic Regression
- Random Forest
- Gradient Boosting
- K-Nearest Neighbors (KNN)

## Tools

- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib
